# 本地用户资料与隐私说明

TurboFlux 本地用户资料不是云账号。一台电脑可以有多份资料，每份资料的数据默认只保存在本机；TurboFlux 不为此功能增加账号、计费、商业遥测或默认上传。

## 资料隔离

每份资料拥有独立的会话、配置、记忆、项目索引、自动化、用户 Skills、Plugins、MCP 私有覆盖、附件与成果索引。同一工作区被两份资料使用时，项目源码仍由项目自身管理，用户私有 Overlay 不共享。

Remote Identity、已配对设备 Grant、Installation ID、活动租约、缓存和系统密文属于设备绑定状态，按资料隔离，但永不进入资料包。切换或回收资料会停止该资料的 Runtime，并撤销相应远程访问上下文。

## 默认导出

默认选择普通偏好、会话与用户记忆；具体选择以导出向导确认页为准。以下内容默认不导出或永不导出：

- API Key、Token、密码和环境变量秘密；
- Remote Identity、设备 Grant 和 Installation ID；
- 工作区绝对路径、Home 目录和项目源码；
- 活动执行、审批、租约、临时文件和缓存；
- 自动化、Plugin、MCP 与大 Blob 等可执行或高风险内容。

用户主动选择 Credentials 时，TurboFlux 强制为完整资料包设置密码。环境变量提供的 Key 不属于 TurboFlux 持久化数据，不能导出。

## 导入后的权限

资料包始终按不可信输入扫描。导入只创建新的非当前资料，不修改现有资料。来源工作区进入未绑定状态；历史可以阅读和再次导出，但在明确选择本机目录前不能继续执行。Automation、Plugin 和 MCP 不会自动启用，也不会继承来源电脑的审批。用户 Skills 先进入当前资料的隔离审查区，不会被 Agent 加载；用户完成来源与内容检查后，应通过受支持的安装流程重新安装或启用。

## 密码与恢复边界

TurboFlux 不保存资料包密码，也没有密码找回或后门。密码丢失后，加密资料包无法恢复。建议将资料包和密码分开保管，并在删除原电脑数据前，在目标电脑完成一次导入、会话对账和工作区重绑定。

## 本地诊断

本地诊断可以记录阶段耗时、错误码、条目数、字节数和重试次数，但不得记录资料名称、完整路径、会话内容、Manifest 秘密或密码。只有用户主动导出诊断时才会生成文件，TurboFlux 不默认上传。
