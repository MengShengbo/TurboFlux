# Figure policy

Final paper figures are generated from the formal benchmark journals, not edited by hand.

- Generated SVG files belong in this directory only after both matrices complete.
- Source values belong in `benchmark-results/2026-07-25-fastcontext-formal-scale/paper-data/`.
- Partial figures must contain an `INCOMPLETE` label and are not publication artifacts.
- Colors remain stable across figures: FastContext `#0F766E`, Claude Code `#B45309`, OpenCode `#334155`.
- Charts must remain legible in grayscale through marker, line, or hatch differences in addition to color.
