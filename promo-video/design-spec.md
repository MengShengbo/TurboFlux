# TurboFlux 产品宣传片设计规范

## 创作模式

- 模式：自主自由创作
- 状态：阶段 0 已放行；阶段 1–3 由 Agent 自主决策并记录
- 业务项目保护：宣传片工程独立放在 `promo-video/`，不改动 TurboFlux 产品源码

## 产品简报

| 项目 | 决策 |
| --- | --- |
| 产品 | TurboFlux CLI，本地终端 AI 工作台与 Coding Agent |
| 核心承诺 | 从一句任务指令，到有证据、可审查、可恢复的工程交付 |
| 主要受众 | AI 编程重度用户、独立开发者、需要多模型与本地工作流的工程团队 |

| 画幅 | 1920×1080，16:9，30fps |
| 语言 | 中文主文案；保留 `FastContext`、`VIBE`、`PLAN`、`Git`、`MCP` 等产品术语 |
| 调性 | 精密、可信、快速，但不浮躁 |
| 核心句 | 一句指令。整个工程开始流动。 |

## 必须展示的产品能力

1. 启动页、ASCII 字标和本地工作区定位。
2. `VIBE / PLAN`、模型与原生推理档位。
3. FastContext 隔离检索：映射、读取、排序、交接证据。
4. 主 Agent、工具调用、后台终端与子代理并行协作。
5. 写入与命令的权限审批界面。
6. Git 状态、结构化 diff 和可审查交付。
7. 长上下文、队列与会话恢复形成持续工作流。

## 需求到执行决策

| 需求 | 实际影响 |
| --- | --- |
| 完整呈现产品差异 | 不做普通聊天窗口剪辑；把证据检索、工具执行、权限与 Git 串成一条因果链 |

## 素材边界

- 可以使用：真实 TurboFlux 启动窗口截图、公开源码片段、虚构任务状态、脱敏 Git 信息。
- 不使用：`.turboflux/server-config.json` 的密钥、原始 runtime journal 内容、真实终端日志、真实对话、内部服务地址。
- 本片不声称像素级复刻产品页面：TurboFlux 是终端应用，为避免真实会话与运行数据入镜，工作台镜头采用直接从源码信息架构、真实 ASCII 字标与品牌 tokens 构建的编辑式系统可视化；真实页面复刻规则不适用，功能图解与所有数据均明确为演示状态。

## 视觉方向

### 候选方向

1. **Evidence Engine**：终端作为黑色机舱，青色结构线承载推理路径，荧光绿只标记证据与完成态。
2. **Agent Constellation**：多个代理卡片围绕中心任务运行，突出协作但弱化真实 TUI。
3. **Signal Pipeline**：抽象数据流从输入穿过工具链抵达 Git，叙事清楚但产品辨识度不足。

### 自主选择

选用 **Evidence Engine**。它直接继承 TurboFlux 的终端设计系统，又能把 FastContext、工具、权限和 Git 组织成一条可见的因果链。Agent Constellation 只作为短暂的协作镜头语法使用；Signal Pipeline 只用于转场，不作为全片皮肤。

### 动效性格 tokens

- 品牌位置：专业信赖 × 中高能量。
- 主入场：24f，`cubic-bezier(0.16, 1, 0.3, 1)`，不弹跳、不 squash。
- 次级信息：18f，同曲线，错峰 3–5f。
- 相机推进：45–60f，`cubic-bezier(0.45, 0, 0.55, 1)`。
- 峰值落定：允许一次 `1.025` 的微过冲，仅用于品牌字标或核心证据卡。
- 常规 hold：24–36f；品牌终帧 hold：45f。
- 三个动效形容词：精密、可信、流动。

### 节奏与连续性

- 片段切点：145 / 276 / 421 / 595 / 726 / 900 帧；均在 124 BPM 拍点 ±1 帧内。
- 能量弧：引信 → 建立 → 证据 → 并行峰值 → 权限降速 → Git 落锤 → 减法收束。
- 镜头只在开场急推一次；FastContext 与 Git 保持正视，代理段允许轻 2.5D。
- 青色表示检索与信息流，绿色只表示已完成/可验证，黄色只表示权限边界。
- 产品画面不复用真实运行日志；路径、分支、命令、任务和 diff 内容均为确定性虚构数据。

## 成片实现约束

- Remotion 工程位于 `promo-video/`，渲染入口为 `TurboFluxPromo`。
- 全片 1080 帧、30fps；任何随机感均使用固定公式，不调用运行时随机数。
- 配乐由本地脚本确定性合成，124 BPM、36 秒，切点加入低频冲击与短促上升噪声。
- 拟音钉帧：打字从 f18 起按 1.45f/字符；回车 f96；代理落位 f451–489；权限确认 f690；Git 行落位 f750–834；交付按钮 f924；品牌 sparkle f1000。
- 交付前逐镜头渲染 QA 静帧，并对最终 MP4 抽帧复检安全区、文字和终帧。
